# AVCIS

Automated Voice Command Intelligent System.

A local-first personal assistant for Windows 11 and Android.

## Objectives

- Responsive voice conversations
- Local AI inference
- Google Search and YouTube integration
- News research and discussion
- Autonomous note preparation
- Local file operations
- Windows and Android automation
- LangChain and LangGraph integration

## Development

- Python 3.13
- Windows 11
- Git
- VS Code
